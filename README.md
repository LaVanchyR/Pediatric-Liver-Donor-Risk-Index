# Pediatric-Liver-Donor-Risk-Index
The code files correspond to the manuscript *A Validated Donor Risk Score to Predict 5-Year Graft Loss or Mortality in Pediatric Liver Transplant Recipients*

All files are written and tested using R 4.5.1. 

Data from the Scientific Registry of Transplant Recipients (SRTR) are required to run these files. These data are available with an approved DUA with the SRTR. This analysis used data from the Standard Analysis File (SAF) as of March 2026. 

An html application for calculating the Pediatric Liver Donor Risk Index for a given patient is available. To run the application, download the PLDRI_calculator.html file and open in a web browser.

Files should be run in this order
- data management.R
- LD analysis.R
- analysis.R
- partial R2 analysis.R
